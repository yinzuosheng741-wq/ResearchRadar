# 证据工作区与交互设计

日期：2026-10-27。此批完善现有桌面对话界面与引用回查流程。

## 已实现

- 欢迎区提供查找证据、比较方法、规划研究路线三个入口，调用现有真实后端。
- 回复的引用集中在证据面板，按 paper_id/chunk_id 去重，显示论文数、全文引用和摘要引用数量。
- “仅基于这篇继续提问”将范围变更排入下一次渲染，在控件创建前与规范论文目录核对，再进入既有 ExecutionContext。论文失效时保持显式空范围，不自动扩大到全库。
- 支持导出当前回答与引用。导出和页面均对未受信内容进行转义、敏感路径/内容隐藏；无引用时明确说明没有论文依据。
- 遗忘上下文后只要仍有历史档案，就继续展示历史，不再叠加首次欢迎页。新对话清除待应用的旧范围操作。
- 清空对话增加明确确认与保留入口；点击入口不会直接删除历史，确认绑定当前对话，新建或切换对话会撤销旧删除意图。
- 采用中性侧栏、居中欢迎区、消息层次和默认折叠的运行诊断；修正首次页面在常见桌面高度下的标题与留白。

```mermaid
flowchart LR
  Answer[引用问答结果] --> Archive[会话档案]
  Archive --> Panel[证据面板与导出]
  Panel --> Intent[用户选择论文范围]
  Intent --> Catalog[规范目录校验]
  Catalog --> Scope[可信 ExecutionContext]
  Scope --> RAG[既有受限检索工作流]
```

界面没有建立独立检索分支，也没有赋予引用文本、会话记忆或文档修改权限的能力。引用面板用于回查位置，不代表所有陈述已经通过语义蕴含校验。

## 验证与后续

378 项测试通过、1 项目录符号链接环境跳过、1 条第三方弃用提示；新增模块 Ruff 通过。新增检查覆盖引用去重、摘要标记、无引用导出、未知/已知论文范围动作、删除确认与取消，以及原有会话保存与遗忘路径。

浏览器核看桌面和 430px 窄窗口。预览使用独立会话库并关闭模型凭据；真实模型、全文解析完整性与语义召回不由此得到验证。

两项目的共享打包脚本加入 Git 文件清单约束，检出目录中的忽略文件不会因位于 docs 等白名单目录而被意外打包。此批未重建带独立 Python 的完整便携包。

完整跨论文比较仍需实验条件与表格证据标注；正文解析、知识覆盖和独立任务验收集继续推进。架构保持单一入口与有界研究工作流，没有增加分析 Agent。
