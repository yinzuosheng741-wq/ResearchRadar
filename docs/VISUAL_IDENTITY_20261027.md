# ResearchRadar 视觉识别与控件精修

本批强化研究工作区的辨识度，并减少按钮、输入和折叠区域层层套框的感觉。

## 文献的独立风格

- 墨蓝侧栏、冷白阅读区、蓝色操作强调，形成明确的导航与内容分区。
- 本地 SVG 雷达标识，配合等宽小标题、左对齐研究介绍与原文回查/范围可控/证据优先说明。
- 证据查找、方法比较、研究路线改为纵向任务入口，使用用途图标和说明文字；与衣橱项目的暖纸色、衬线标题、双列灵感入口区分。
- 对话用户气泡、草稿区与输入区采用更克制的圆角；保留原有检索范围、引用面板和确认流程。

## 控件与可读性

移除重复的常驻描边，用表面底色、悬停和清晰的主操作区分可操作内容，保留键盘与输入焦点。兼容新版 React Aria 和旧版 BaseWeb 控件，修复深色侧栏中选择框、搜索框露出默认白色背景导致对比不足的问题。

纵向任务的文字、图标和说明对齐，收紧布局以减少首次自动滚动遮住页头。所有图标和字体回退都在本地运行，不依赖外部视觉资源。

## 验证范围

任务草稿、会话管理和引用面板相关 12 项回归通过，健康检查、编译和差异格式检查通过。本批不改变惰性研究服务、检索、Agent 权限或引用校验，不报告召回率或模型效果变化。

实际浏览器检查欢迎页、深色导航、任务草稿和取消操作；使用独立会话库，关闭外部模型。

两项目均实际检查 430px 窄屏，页面宽度与视口一致，没有横向溢出。
