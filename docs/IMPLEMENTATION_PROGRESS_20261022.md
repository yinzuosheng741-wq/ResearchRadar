## 4. 本批代码变更

1. `retrieval/context.py`：先保留全部规范直接命中，再添加邻块；避免数据库按论文排序返回邻块时挤掉直接命中。只接受已验证命中所属论文和当前可信范围内的邻块。
2. 可选邻块加载失败时保留直接证据；规范正文和元数据优先于过期载荷。复用已经从数据库加载的规范块，避免额外重复查询。
3. `workflows/qa.py`：单个证据块不再直接触发拒答，允许模型生成并通过引用校验的直接回答；超时后证据不足的 trace 不再标记为 answerable。引用定位校验不再被描述成语义支持验证。
4. `evaluation/run.py`：论文归属使用 EvidenceChunk.paper_id，不再从 chunk_id 字符串猜测。
5. `evaluation/corpus_audit.py`：增加只读语料统计、内容指纹、标注有效性校验、关键词 @5/@20 诊断；失效标注单列，不混入有效样本平均值。
6. 新增回归覆盖直接命中保留、邻块失败、范围约束、单块回答和只读审计。旧的 `assistant_runtime` 标为未接入实验，修正其导入格式问题。

本批没有改变关键词检索算法，因此以上 Recall 为基线，不是优化后提升值。上下文正确性修复由回归场景验证，不能直接换算为真实回答准确率。
