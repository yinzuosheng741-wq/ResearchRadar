## 第二批：摘要与正文细节的回答边界

新增 `retrieval/evidence_requirements.py`：只检索到摘要且问题明确要求学习率、超参数、表格、公式、附录或补充材料等细节时，在答案生成前返回缺少全文的说明，设置独立 trace 状态，不产生支持该细节的引用。
