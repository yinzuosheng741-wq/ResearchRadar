# ResearchRadar 业务与桌面升级记录

## 已交付

1. 多查询检索不再按第一个查询占满上下文。各查询候选通过 RRF 融合，保留查询代表证据；失败分支不抹掉成功结果。
2. 论文初筛后增加全范围 chunk 分支；显式论文范围不会放宽。
3. 复杂比较问题引入独立证据审阅角色，提出缺失方面，最多补检两个查询；综合角色仍校验本地引用。审阅不是事实正确性认证。
4. 路由规划子查询传入 Skill；可信调用方可提供论文范围、可用 Skill 和模型／工具／检索预算。嵌套模型调用计入请求及 Skill 限额，阶段边界检查超时。
5. 安全运行诊断显示实际调用计数；模型和文献无法更改后端权限。当前仍为单用户本地系统。
6. 增加 Start.cmd、desktop.py、独立嵌入式 Python 分发包、可重建打包脚本和依赖锁定清单。参见 DESKTOP.md。

## 验证

2026-10-22，源码完整 pytest：343 项通过、1 项跳过。新增测试覆盖后续子问题命中、分支失败、显式空范围、越范围候选、共享预算、拒绝越权 Skill，以及比较问题补检。

便携包在独立解压目录使用自带 Python 启动页面，已完成页面无异常检查；共享 WebView2 运行时通过隐藏窗口创建／关闭测试。HTTP 健康检查只验证服务启动，不替代真实模型与外部 provider 联调。

尚未在冻结真实语料上重跑原 48 问检索评测，不宣称历史 65.63% 指标已提高。无需联网的回归用例仅证明新增机制与边界生效。

## 下一阶段的验收目标

- 固定语料、索引、Embedding 与评测集版本，单独划分调参集和保留测试集。
- 对关键词、向量、权重、多查询、两阶段旁路及证据补检做消融；报告 Recall@5/@20、证据组覆盖、延迟和模型调用成本。
- 增加引用支持关系人工标注，区分原文存在与语义支持。
- 加入论文比较表及逐单元格引用；再评估版面／表格解析和 OCR 的收益。
- 桌面后续完善进度事件、取消、模型设置界面和真实语料导入引导。当前浏览器 UI 已运行于原生窗口，尚未完成独立前端重写。
